# Ronco real do motor

Coloque aqui uma gravação real e autorizada do motor da Malibu Response LX com o nome:

`malibu-response-lx-v8.mp3`

O botão "Ouvir V8" tenta tocar esse arquivo primeiro. Se ele não existir, a página usa uma simulação WebAudio como fallback para não quebrar a experiência.

Recomendado:
- 8 a 20 segundos em loop limpo.
- Sem música de fundo e sem voz.
- Normalizar o volume para evitar estouro no celular.
- Confirmar autorização do proprietário da gravação antes de publicar.
